# heading

Section title, `h1`–`h4`, in the display type scale.

| Field | Type | Notes |
| --- | --- | --- |
| `text` | string | The heading text (≤500 chars) |
| `level` | `h1 \| h2 \| h3 \| h4` | Semantic + visual level |
| `align` | `left \| center \| right` | Text alignment |

```json
{ "text": "Simple, honest pricing", "level": "h1", "align": "center" }
```
