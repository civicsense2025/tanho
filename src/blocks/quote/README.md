# quote

Pull quote — accent left rule, display-size text, attribution in mono uppercase.

| Field | Type | Notes |
| --- | --- | --- |
| `text` | string | The quote itself (≤1000 chars) |
| `cite` | string | Attribution line, rendered in mono (≤200 chars) |

```json
{ "text": "The details are not the details. They make the design.", "cite": "Charles Eames" }
```
